# Weather Images Classification Hyperparameter Optimisation

### Workflow
1. Install the required Weights and Biases library by executing the following command in a terminal window:
   `. setup.sh`
3. Choose the desired settings for the hyperparameter sweep in `weather-images-hpo-script.py`. Pick a project ID. 
4. Run the sweep by executing the following command in a terminal window:
   `python weather-images-hpo-script.py`
6. Open the Weights and Biases interface in a browser and explore
