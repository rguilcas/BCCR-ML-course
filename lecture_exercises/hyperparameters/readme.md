# Weather Images Classification Hyperparameter Optimisation

### Workflow
1. Install the required Weights and Biases library
In a terminal window: `. setup.sh`
2. Choose the desired settings for the hyperparameter sweep in `weather-images-hpo-script.py`. Pick a project ID. 
3. Run the sweep
In a terminal window: `python weather-images-hpo-script.py`
4. Open the Weights and Biases interface and explore
